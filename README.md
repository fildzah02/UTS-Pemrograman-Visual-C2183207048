## Deskripsi Aplikasi

Aplikasi Kasir Kantin Kampus merupakan aplikasi desktop
sederhana yang dibuat menggunakan bahasa pemrograman Java
dan Java Swing melalui Apache NetBeans IDE.

Aplikasi ini digunakan untuk membantu proses transaksi
pembelian makanan dan minuman di kantin kampus.

Aplikasi dapat menghitung total harga, menerima pembayaran,
menghitung uang kembalian, serta memberikan peringatan
apabila pembayaran kurang atau input tidak valid.

Aplikasi ini tidak menggunakan database.

## Fitur Aplikasi

1. Input nama makanan atau minuman.
2. Input harga satuan.
3. Input jumlah pembelian.
4. Menghitung total harga.
5. Input uang pembayaran.
6. Menghitung uang kembalian.
7. Validasi input kosong.
8. Validasi angka dan nilai negatif.
9. Peringatan pembayaran kurang.
10. Reset formulir transaksi.

## Komponen Java Swing

- JFrame
- JPanel
- JLabel
- JTextField
- JButton
- JOptionPane
- JSeparator

## Rumus Perhitungan

Total Harga = Harga Satuan x Jumlah Pembelian

Kembalian = Uang Pembayaran - Total Harga
